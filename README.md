# Garden-Design-Management-System
 Big Data &amp; Database Management Systems Project

This project was developed as part of my Big Data and Database Systems module. The aim was to design and implement a database system for a garden design business, supporting customer records, staff information, services, bookings, payments, and reporting.

## Key Features
- Designed an ERD to model business data requirements
- Applied normalisation principles to reduce duplication
- Created SQL tables with primary and foreign keys
- Inserted sample business data for testing
- Wrote SQL queries to generate useful business reports
- Produced dashboard-style outputs to support decision-making

## Tools Used
- SQL Server / SSMS
- Power BI
- Draw.io / ERD design tool
- Microsoft Excel

## Skills Demonstrated
- Database design
- SQL development
- Data modelling
- Business reporting
- Data visualisation
- Problem-solving and documentation

## Relevance
This project helped me understand how structured data can support business operations and management decisions. It also developed my interest in data analytics, reporting, and database-backed systems.
